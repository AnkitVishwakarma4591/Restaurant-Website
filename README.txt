SAFFRON & EMBER — RESTAURANT WEBSITE DEMO

Files
- index.html: website structure and page content
- style.css: responsive styling, layout, colours and typography
- script.js: mobile navigation, date validation and booking form connected to Google Sheets and Supabase
- supabase-setup.sql: bookings table and row-level security setup

Run locally
1. Keep all three files in the same folder.
2. Double-click index.html, or open it with Chrome/Edge.
3. An internet connection is needed for Google Fonts and the Unsplash food/interior photos.

IMPORTANT CUSTOMISATION BEFORE PUBLISHING
- The provided Google share link could not be resolved to a restaurant listing by the available browser, so “Saffron & Ember” is a placeholder brand, not a verified restaurant name.
- Replace the placeholder restaurant name, story, menu categories, contact details, opening hours and location with verified business details.
- Replace the sample food images with the restaurant's own photos where possible.
- The reservation form saves booking requests to Supabase and sends them to the configured Google Apps Script web app. The web app should be deployed to run as the sheet owner and accept requests from anyone.
- Review the image licences and ensure you have permission to use all assets before publishing.
